# data/

| File | What it is |
|---|---|
| `sample_traffic.csv` | **SYNTHETIC demo data** (hourly, all of 2017, 8,760 rows) loaded when the app first starts or when you press *Reset to demo data*. Randomly generated by `generate_sample_data.py`. It is **not** real traffic. |
| `sample_spark_results.zip` | A ZIP in the same format as the Colab notebook's output, built from the synthetic data, so you can try **Import Spark Results** without running Colab. Its summary is marked `"is_synthetic": true`. |
| `generate_sample_data.py` | Regenerates both files above (`python data/generate_sample_data.py`). |
| `traffic.db` | Created automatically at run time (SQLite, git-ignored). Delete it to start fresh. |

The real analysis uses the UCI *Metro Interstate Traffic Volume* dataset, which is downloaded inside the Colab notebook and is not stored in this folder.
